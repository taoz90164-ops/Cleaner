# Cleaner

让 AI 帮你看清磁盘占用，再像玩水果忍者一样挑选垃圾。

Cleaner 是一个给本地 AI Agent 使用的 Windows 磁盘清理 Skill，支持 C 盘、D 盘等任意本地盘符。它把扫描结果做成可离线打开的交互网页，适合不熟悉电脑目录、也不想自己写命令的用户。

扫描后生成可离线打开的 HTML 报告，用水果忍者式划动或按钮挑选清理项目。确认导出后，将 TXT 清单发回有本地执行能力的 Agent，由它核验并处理名单范围。

## 使用方法

1. 点击仓库右上方 **Code → Download ZIP**，或[直接下载](https://github.com/taoz90164-ops/Cleaner/archive/refs/heads/main.zip)，然后解压。
2. 将完整文件夹导入 Agent 的本地 Skill 入口，或让它读取文件夹中的 SKILL.md。
3. 告诉 Agent：“扫描 C 盘，报告放桌面。”盘符可以替换。
4. 打开报告，挑选项目，核对后导出清单。
5. 将清单发回 Agent，开始核验与清理。仅需检查时请明确说“只检查，不删除”。

第一次使用可以直接把下面这句话发给 Agent，把路径换成你实际解压的位置：

> 读取这个文件夹里的 SKILL.md，使用 Cleaner 完整扫描 C 盘，生成报告放到桌面。

打开报告后，按住鼠标左键划过推荐卡片即可加入垃圾车，也可以使用按钮或按分类全选。选错了可在清单中撤销；点击“生成清理清单”，核对后导出 TXT，再把它发回同一个 Agent。

如果客户端支持 Skill 导入，请导入包含 **SKILL.md、assets、scripts、references** 的完整文件夹，不要只导入 HTML 或单独的 SKILL.md。新手指南也随项目提供。

## 功能

- 扫描真实占用，按缓存、安装与更新文件等分类展示。
- 软件和个人资产分区展示；软件卸载走官方入口。
- 切割动效、音效、分类全选、垃圾车及导出确认。
- 导出后隐藏已交付项目，选择与预览进度归零。
- 执行前核验文件身份与目录成员，变化、链接或受保护项目跳过。

## 运行要求

Windows、本地文件读写及命令执行能力；Windows PowerShell 5.1 或 PowerShell 7。无需额外安装 Python 或 Node.js，页面无需构建工具。

适用于有本地执行能力的 Codex、Claude Code、WorkBuddy、豆包工作、百度工作搭子等 Agent；客户端接入及实际验证范围见 references/compatibility.md。

## 清理范围

扫描与浏览报告不会删除文件。执行清单会永久删除通过核验的选中废料，不经过回收站。软件通过官方卸载入口处理；个人资料和系统组件不作为整目录清空目标。请在导出前核对选项。

导出后的卡片移除表示“已交付清单”，不表示磁盘文件已经删除；实际结果以 Agent 执行后的核验为准。正在使用、扫描后变化或读取不完整的项目可能被跳过。客户端权限与系统卸载界面仍可能需要用户操作。

## 文件说明

- SKILL.md：Agent 使用入口与工作规则。
- 新手使用规则.txt：五步大白话指南。
- assets/：固定 HTML 模板及校验值。
- scripts/：扫描、报告生成、核验执行和打包脚本。
- references/：分类、数据契约、执行及兼容说明。

本仓库不包含个人磁盘扫描报告、导出清单和测试数据。
